# 黑话桥词典（v6.0 理解优先版新增）

> **用途**：治「金融/商业黑话裸奔」——日报读者（微电子大二学生）的卡点词在这里统一翻译成「人话 + 课内类比」。与 `glossary.md`（译名一致性）分工：glossary 管「英文怎么译成中文」，本表管「中文黑话怎么翻译成人话」。
> **写作纪律**：写作前先查本表；C 档词正文默认禁裸用（换白话或首现给翻译）；**禁止用 C 档词解释 C 档词**；同一概念全篇至多两处解释性文字（首现处 + 术语阶梯）。
> **三档判断口诀**：能用课内语言解释 = A 档；一句话能说清 = B 档；解释它还得先解释另外三个金融词 = C 档。

## 种子表（黑话 → 人话 → 课内类比）

| 黑话 | 人话 | 课内类比/锚 | 档 |
|------|------|------------|----|
| 营收 | 公司这段时间卖货收了多少钱 | —（白话替代：卖了多少钱） | C |
| 毛利率 | 每卖 100 元货，扣除直接生产成本后剩多少 | 类似「成品率决定成本」，良率越高剩得越多 | C |
| 归母净利 | 扣完所有成本税费后、真正属于股东的利润 | —（C 档，白话替代） | C |
| 资本开支（Capex） | 建厂、买设备的钱 | 买实验设备扩建实验室的那笔大钱 | C |
| 法说会 | 业绩说明会：公司高管向投资者汇报并答问 | 期末答辩：讲成绩 + 回应追问 | C |
| 指引 | 公司对下一季度业绩的官方预估区间 | 实验报告里的「预期结果」栏 | C |
| 利好 | 事件对产能/订单/技术是正向的（非股票预言） | 正反馈方向 | C |
| 景气 | 行业订单多、产线忙的程度 | 供不应求的状态 | C |
| 高基数 | 去年同期数字本来就高，所以今年增速看起来小 | 与上次实验的高分基线比较 | C |
| 顺价 | 成本涨了，把涨价转给下游客户 | 传递函数：输入涨、输出跟着涨 | C |
| 配股 | 向老股东按比例要钱 | —（C 档，词典备查） | C |
| 可转换债券 | 可按约定转成股票的借条 | —（C 档，词典备查） | C |
| 去产能 | 用涨价/减产把多余产能挤出去 | 负反馈调节 | C |
| 流片（tape-out） | 把设计好的版图交给工厂生产第一批样品 | 交版图「下厂加工」 | B |
| 良率 | 一片晶圆上合格芯片的比例 | 实验成功率 | B |
| 产能利用率 | 产线实际用量/满载能力的百分比 | 负载率 | B |
| 光罩（Reticle） | 光刻用的「底片」，图案经它缩印到晶圆 | 照相底片/掩膜 | B |
| 签核（Sign-off） | 流片前最后一道设计正确性盖章 | 提交前的最终检查清单 | B |
| NPO / CPO | 光引擎靠近芯片 / 进入封装的光互连两代方案 | 把「光电转换器」越搬越近 CPU 的两步走 | B |

## 每期增量维护规则

1. **写作前先查本表**：Step 3 摘要与子行写作时，卡点词一律先查（A 档词另见 `glossary.md` 译名 + 日报「术语阶梯」）。
2. **新卡点词当期入表**：本期日报出现、本表没有的黑话（尤其 C 档金融词），当期把「黑话｜人话｜课内类比｜档」补进上表——宁可多一行，不留裸奔词。
3. **入表时机**：Step 4 组装完成后、Step 5 校验前，顺手补行（保持表格按档位分区即可，不强制排序）。
4. **第二阶段联动**：`scripts/validate_understanding.py`（U2 C 档词裸用检测，WARN-only）实现时，C 档词清单以本表「档=C」行为准——届时按 X7 硬门禁走 `rules/rule_registry.yaml` 三端同步，不手写进脚本。
