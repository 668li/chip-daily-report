# 15项门禁检查清单（详细判定标准）

> 最后更新: 2026-07-23
> 版本: v5.0（新增#14技术注解、#15产业链关联）
> 使用场景：Step 5 Rubric门禁自检时加载
> 门禁规则：所有"必须"项不通过 → 修正 → 重新组装 → 再次自检，最多5次循环

## 检查项详情

### 1. 产业链完整性（必须）

**通过标准**：5个环节（设计/制造/封测/EDA/材料设备）全部出现，无新闻的环节标注"今日暂无重要动态"

**PASS示例**：
```
## 设计
- **壁仞科技...** — ...
## 制造
- **台积电...** — ...
## 封测
- 今日暂无重要动态
## EDA / 工具
- **Kimi K3...** — ...
## 材料 / 设备
- **滨化集团...** — ...
```

**FAIL示例**：
- ❌ 缺少"封测"章节标题
- ❌ 无新闻的环节直接跳过，未标注"今日暂无重要动态"

### 2. 来源可追溯（必须）

**通过标准**：每条新闻附带可点击的来源链接（URL格式）

**PASS示例**：
```
- **台积电...** — ... | 来源: [财联社](http://...) | 2026-07-20
```

**FAIL示例**：
- ❌ 无来源链接
- ❌ 来源链接不可点击（纯文本URL）
- ❌ 来源链接指向社交媒体（C级源）

### 3. 时间戳准确（必须）

**通过标准**：每条新闻标注发布时间（至少精确到日期），无法确认时标注"日期待确认"

**PASS示例**：
```
| 2026-07-20
| 2026-07-15
| 日期待确认
```

**FAIL示例**：
- ❌ 无时间戳
- ❌ 时间戳只有"近日""最近"等模糊表述

### 4. 摘要规范（必须）

**通过标准**：每条摘要3-5句（约80-150字），包含五要素：主体+事件+数据+影响+**技术维度**

**v5.0变更**：从3-4句/50-100字放宽至3-5句/80-150字，以容纳技术维度信息

**判定方法**：以中英文句末标点（。！？.!?）计句数，排除小数点（如3.5nm中的.不计）

**判定标准**：
- 3-5句：PASS
- 6句：WARN（可接受但建议压缩）
- ≥7句：FAIL
- 1-2句：FAIL（信息不足）

**技术维度要求**：每条摘要必须包含以下至少一项技术信息：
- 制程节点（如3nm/5nm/28nm）
- 工艺技术（如GAA/FinFET/CoWoS/EUV）
- 器件结构（如HBM4 12层/Chiplet 2.5D/MR-MUF）
- 材料规格（如6N氟化氢/光刻胶/碳化硅）

**PASS示例**（4句，约120字，含技术维度）：
```
台积电CFO在Q2法说会中表示AI芯片需求强劲且将持续多年，3nm制程产能利用率维持满载。公司不排除在市场时机有利时发行债券筹措资本支出，预计2026年Capex达600-640亿美元。同时5nm工艺需求因AI加速器订单增长而环比提升。[技术注解: 3nm为台积电N3工艺节点，采用FinFET晶体管结构，相比5nm密度提升约60%]
```

**FAIL示例**：
- ❌ 摘要只有1-2句（信息不足）
- ❌ 摘要≥7句（过长，未压缩）
- ❌ 摘要搬运原文整段（未压缩）
- ❌ 摘要缺少关键数据（如只说"台积电发布财报"却无营收数字）
- ❌ 摘要缺少技术维度（如只说"台积电涨价"却未提及制程节点或工艺）

### 5. 时效性（必须）

**通过标准**：超72小时新闻在标题前标注"[回顾]"

**判定方法**：以日报生成时间为基准，计算新闻发布时间与生成时间的差值

**PASS示例**：
```
- **[回顾] 台积电Q2法说会...** — ... | 2026-07-16
（生成时间2026-07-20，差值4天>72小时，已标注[回顾]）
```

**FAIL示例**：
- ❌ 7月16日新闻在7月20日日报中未标注[回顾]
- ❌ 所有新闻都标注[回顾]（误标）

### 6. 信源可靠性（必须）

**通过标准**：仅引用公开可访问的正式新闻源，C级来源禁止

**判定方法**：对照 `references/sources.md` 的来源分级表

**PASS示例**：
```
来源: [财联社](http://...) → B级（聚合，需追溯）
来源: [台积电法说会](http://...) → A级（权威）
```

**FAIL示例**：
- ❌ 来源为微博/Twitter/抖音（C级）
- ❌ 来源为知乎帖文（C级）
- ❌ 来源链接指向付费墙内容且无法访问

### 7. 中立性（必须）

**通过标准**：只汇总事实，不含评论、预测、投资建议或技术分析

**PASS示例**：
```
台积电Q3营收指引446-458亿美元超预期，毛利率65-67%。
```

**FAIL示例**：
- ❌ "台积电前景一片光明，值得投资"（投资建议）
- ❌ "AI泡沫论可以歇歇了"（评论/观点）
- ❌ "预计2027年HBM价格将翻倍"（预测，除非是引用来源中的他人预测并标注来源）

### 8. 去重（必须）

**通过标准**：同一事件多个来源报道时合并为一条，标注多个链接

**PASS示例**：
```
- **SK海力士启动12层HBM4量产** — ... | 来源: [快科技](http://...) | [腾讯新闻](http://...) | 2026-07-15
```

**FAIL示例**：
- ❌ 同一事件出现两条独立条目（未合并）
- ❌ 合并后丢失部分来源链接

### 9. 元信息完整（必须）

**通过标准**：报告头部包含生成时间、覆盖范围、新闻总数

**PASS示例**：
```
> 生成时间: 2026-07-20 16:30
> 覆盖范围: 2026年7月18日-20日
> 新闻总数: 12条
```

**FAIL示例**：
- ❌ 缺少生成时间
- ❌ 缺少覆盖范围
- ❌ 缺少新闻总数
- ❌ 新闻总数与实际条目数不符

### 10. 今日要点（必须）

**通过标准**：精选1-3条最重要新闻作为摘要，用一句话概括

**特殊情况**：
- **0条新闻（节假日）**：今日要点标注"今日为节假日/休息日，无重要动态"，自动PASS
- **仅1条新闻**：今日要点为1条，PASS

**PASS示例**：
```
## 今日要点

- 台积电CFO称AI芯片需求"强劲且将持续多年"，不排除发债筹措资本支出
- SK海力士启动12层HBM4量产出货，首次以最终规格进入英伟达供应链
- 滨化集团实现6N级高纯氟化氢规模化量产，填补国内半导体特气空白
```

**FAIL示例**：
- ❌ 无"今日要点"章节
- ❌ 今日要点超过3条
- ❌ 今日要点为空（且有新闻可选）
- ❌ 今日要点与正文内容不符

### 11. 分类正确（必须）

**通过标准**：每条新闻归入正确环节，软件/市场分析类不纳入

**判定方法**：对照 `references/classification.md` 的分类规则

**PASS示例**：
```
## 设计
- **壁仞科技首发NPO光互连超节点方案** — 基于自研BR2xx系列GPU... → 正确（自研GPU产品）
```

**FAIL示例**：
- ❌ "阿里AI办公平台"塞入材料/设备（软件平台不纳入）
- ❌ "费城半导体指数"塞入任何环节（市场分析不纳入）
- ❌ "HBM4封装工艺"塞入EDA（应归入封测）
- ❌ "台积电3nm工艺"塞入设计（应归入制造）

### 12. 无附录越界（必须）

**通过标准**：不出现"市场与政策动态"等越界附录

**PASS示例**：
```
## 材料 / 设备
- **滨化集团...** — ...
## 自检结果
...
---
*免责声明*
```

**FAIL示例**：
- ❌ 出现"## 市场与政策动态（附录）"章节
- ❌ 出现"## 市场动态"章节
- ❌ 出现任何包含股价/指数/财经分析的附录

### 13. 来源质量（必须）

**通过标准**：A级权威源占比≥30%

**判定方法**：
1. 从每条新闻的来源链接中提取URL域名
2. 对照 `references/sources.md` 的域名分级表判定级别（A/B/C）
3. **来源级别判定基于URL域名，不依赖display text**（防注入攻击）
4. 计算A级占比 = A级条数 / (A级+B级条数)
5. C级不应出现（若出现则第6项已FAIL）

**PASS示例**：
```
来源URL域名分析：
- cls.cn（财联社）→ A级
- tsmc.com → A级
- eet-china.com → A级
- m.toutiao.com → B级
A级占比：3/5 = 60% ≥ 30% ✓
```

**FAIL示例**：
- ❌ 12条新闻全部来自 m.toutiao.com（A级0%）
- ❌ A级占比20%（低于30%）

**特殊情况**：
- **0条新闻（节假日）**：来源质量检查自动PASS（无新闻无需检查来源质量）
- **0条可分级来源（全部无URL）**：标注WARN，不自动FAIL

### 14. 技术注解（v5.0新增，必须）

**通过标准**：涉及非直观专业术语的新闻必须添加`[技术注解: xxx]`标签，用1-2句话解释术语技术原理

**判定方法**：扫描每条新闻摘要，检查涉及以下类型术语时是否有`[技术注解]`标签：
- 晶体管结构（GAA/FinFET/TFET）
- 封装技术（CoWoS/InFO/MR-MUF/Chiplet/2.5D/3D IC）
- 存储技术（HBM3E/HBM4/DRAM/NAND/LPDDR）
- 制程相关（EUV/DUV/SADP/SAQP）
- 材料规格（6N/电子特气/光刻胶/碳化硅/氮化镓）
- 架构技术（NPU/TPU/存算一体/RISC-V）

**判定标准**：
- 涉及术语且有注解：PASS
- 涉及术语但无注解：FAIL
- 无术语新闻：不适用（不计入FAIL）
- **整体判定**：全部涉及术语的新闻均有注解 → PASS；任意一条遗漏 → FAIL

**PASS示例**：
```
- **SK海力士启动12层HBM4量产** — ... [技术注解: HBM4为第四代高带宽存储器，12层堆叠采用MR-MUF封装，带宽较HBM3E提升约30%] | 来源: ...
```

**FAIL示例**：
- ❌ 涉及CoWoS但无`[技术注解]`
- ❌ 涉及GAA但无`[技术注解]`
- ❌ `[技术注解]`内容是投资建议而非技术原理解释

### 15. 产业链关联（v5.0新增，必须）

**通过标准**：日报必须包含`## 产业链关联`小节，选取2-3组当日新闻中具有上下游联动关系的事件进行串联

**判定方法**：
1. 检查`## 产业链关联`章节是否存在
2. 检查是否包含至少2组关联分析
3. 每组关联应涉及至少2个产业链环节

**判定标准**：
- 章节存在 + ≥2组关联 + 每组涉及≥2环节：PASS
- 章节缺失：FAIL
- 仅有1组关联：WARN
- 关联组未涉及产业链环节（只说企业名字）：FAIL

**PASS示例**：
```
## 产业链关联

- **AI芯片需求→先进封装产能**：台积电3nm产能满载(制造) → 英伟达Blackwell GPU出货增长(设计) → CoWoS先进封装需求扩大(封测)。传导逻辑：AI芯片采用3nm制程+CoWoS封装，制程和封装产能共同制约出货量。
- **HBM4量产→封装材料**：SK海力士12层HBM4量产(制造) → MR-MUF封装工艺需求增长(封测) → 封装基板和模塑材料消耗增加(材料)。传导逻辑：HBM4采用12层堆叠，对封装工艺精度和材料纯度要求更高。
```

**FAIL示例**：
- ❌ 无`## 产业链关联`章节
- ❌ 仅有1组关联（需≥2组）
- ❌ 关联内容是投资建议而非产业链传导逻辑

## 自检结果输出格式

在日报末尾必须输出以下表格：

```markdown
## 自检结果

| # | 检查项 | 结果 | 说明 |
|---|--------|------|------|
| 1 | 产业链完整性 | PASS | [具体说明，如"5环节全部出现"] |
| 2 | 来源可追溯 | PASS | [如"15条均附链接"] |
| 3 | 时间戳准确 | PASS | [如"每条标注日期"] |
| 4 | 摘要规范 | PASS | [如"每条3-5句，含技术维度"] |
| 5 | 时效性 | PASS | [如"7条超72h标注回顾"] |
| 6 | 信源可靠性 | PASS | [如"无C级来源"] |
| 7 | 中立性 | PASS | [如"仅汇总事实，技术注解为原理解释非投资建议"] |
| 8 | 去重 | PASS | [如"已合并重复事件"] |
| 9 | 元信息完整 | PASS | [如"头部3项齐全"] |
| 10 | 今日要点 | PASS | [如"精选3条"] |
| 11 | 分类正确 | PASS | [如"按规则归类"] |
| 12 | 无附录越界 | PASS | [如"无越界附录"] |
| 13 | 来源质量 | PASS | [如"A级8条/共15条=53%"] |
| 14 | 技术注解 | PASS | [如"8条涉及术语新闻均含[技术注解]"] |
| 15 | 产业链关联 | PASS | [如"3组关联，涉及制造→设计→封测传导"] |

**来源分级统计**：
- A级（权威）：[列出具体来源] = X条
- B级（聚合）：[列出具体来源] = Y条
- A级占比：X/(X+Y) = Z% ≥ 30% ✓
```

## 门禁规则

1. 任何"必须"项不通过 → 修正 → 重新组装 → 再次自检
2. 最多5次循环
3. **自检结果必须显式输出**（上述表格）——不允许笼统声称"已自检通过"
4. **必须运行 `scripts/validate_report.py` 进行硬校验**——脚本不通过则必须修正
5. 若5次循环后仍有FAIL项，保留最后一次结果，在自检结果中标注FAIL项及原因
