# Chip Daily Report

> 类型 P4：产物生成型

生成带来源和时间戳的芯片行业日报，覆盖设计、制造、封测、EDA、材料、设备等全产业链。

## 工作流

1. 确认日期范围和关注领域，默认取最近一个工作日。
2. 按产业链环节收集新闻：设计（GPU/CPU/AI芯片）、制造（先进制程/成熟制程）、封测、EDA、材料与设备。
3. 为每条新闻标注来源链接和发布时间戳。
4. 按重要性排序，生成结构化日报。

## 输出格式

```markdown
# 芯片行业日报 — [日期]

## 设计
- **[标题]** — [摘要] | 来源: [链接] | [时间戳]

## 制造
...

## 封测
...

## EDA / 工具
...

## 材料 / 设备
...
```

## 失败处理

| 情况 | 修复 | 兜底 |
|---|---|---|
| 来源链接失效 | 标注"链接待验证" | 保留标题和摘要 |
| 无法确认时间 | 标注"日期待确认" | 只保留日期不保留时分 |
| 无新闻的环节 | 标注"今日暂无重要动态" | 不省略该环节 |

## 边界

- 只汇总公开可访问的新闻来源，不引用付费墙内容。
- 不做投资建议或市场预测。
- 时间戳以来源页面的发布时间为准，不做时区换算推断。
