# Chip Daily Report

> 类型 P4：产物生成型 · v5.8 专业深度版（微电子视角+技术解读+产业链关联+来源分层+信号层+跨日记忆+催化剂日历+深度解读+未来借鉴+今日导师课）

## 设计哲学

- **信源优先**：每条新闻必须可追溯至原始来源，拒绝二次转载未标注出处的内容。
- **产业链完整性**：宁可某环节标注"暂无动态"，也不省略环节——完整性是日报可信度的基石。
- **时效性优先**：默认覆盖最近一个工作日，超72小时的内容需标注"回顾"。
- **事实与技术分离**：事实汇总为正文，技术解读为`[技术注解]`标签——技术解读解释"这个技术是什么、为什么重要"，不是投资建议。
- **来源分级**：权威源优先，聚合页次之，社媒禁止——来源质量基于URL域名判定，不依赖display text。
- **执行闭环**：规则必须可执行、可验证——Rubric是门禁不是装饰，校验脚本是硬约束不是建议。
- **微电子专业视角**：日报面向微电子/IC专业读者，每条新闻应包含技术节点、工艺、器件等维度信息，帮助读者将产业动态与课堂知识连接。
- **信号优先（v5.2）**：日报不只是"漂亮的RSS"——每条新闻标注重要性/影响方向/情绪，让读者一眼知道"什么值得看、往哪个方向看"。

生成带来源、时间戳和技术注解的芯片行业日报，覆盖设计、制造、封测、EDA、材料、设备等全产业链。

## 生成流程（6步高效流程 + Step 7 周度复盘，v4.0合并优化）

> v3.2→v4.0 变更：10步→6步，合并时效标注/去重/排序到搜索阶段，来源分级即时判定，目标单次通过门禁。

### Step 1: 确认范围（5秒）
- 询问/确认日期范围（默认最近一个工作日）和关注领域
- **【B】读取跨日记忆**：读取 `state/report_state.yaml`，提取「持续追踪主题」列表（方向/连续期数/变比）。文件缺失或损坏时跳过，不阻塞生成。
- **非交互模式**（如定时任务）：使用默认值（最近一个工作日），不等待用户输入
- 输出：`[日期范围]` + `[关注领域]` + `[生成时间]`（用于后续72小时计算基准）+ `[持续追踪主题]`

### Step 2: 搜索+分级+筛选（一站式，~4分钟）
- **【强制】先执行文件读取**：读取 `references/sources.md` 获取A级域名清单和搜索关键词模板
- **【X17】来源池优先级（v5.2新增，治"漂回中文聚合源"）**：搜索调用顺序严格按 `references/sources.md` 末尾的「信号来源分层」执行——**Tier-0 公司一手（IR/法说会/官方公告）→ Tier-1 英文权威行业媒体（SemiAnalysis/DigiTimes/EE Times/SE/SemiEngineering/TrendForce/The Elec）→ Tier-2 监管/财报原始文件（SEC EDGAR/上交所/深交所/MOPS/DART）→ Tier-3 中文权威（A级白名单）→ Tier-4 聚合（仅作线索）**。
  - 每期先从 **Tier-0/1 取 ≥3 条一手/英文信号**，再补 Tier-3 中文权威；英文源占比偏低时优先补 Tier-1，**不得以 Tier-4 中文聚合充数**。
  - 财报季（1/4/7/10 月及前后）必须将 Tier-0 法说会 + Tier-2 8-K 作为「重点企业动态」重点覆盖。
  - 每条 Tier-4 聚合源必须标注「原始: X」追溯（与 X14 一致）。
- **【AIHOT 线索源，v5.7新增，迭代2升级】**：已安装 AIHOT Skill（`~/.workbuddy/skills/aihot`，匿名只读 API 无需 Key，Skill 1.4.1/MIT）作为**第一个新增数据源**（Tier-4 线索源，B 级）。Step 2 首轮搜索后，可用 AIHOT 做**漏检补充 + 热点捕捉**：`curl "https://aihot.virxact.com/api/v1/items?mode=all&window=7d&q=<关键词URL编码>&limit=8"` 查候选新闻，命中后按 `links.original` 追溯第三方原文或换 A 级中文源承载。**迭代2（2026-08-09）已升级为 `scripts/multi_source/collector.py` 正式源**（AIHOTCollector 适配器），online 模式 4 源真实采集（SEC/AIHOT/SemiEngineering/EE Times，单次 44-47 条）。纪律：中文关键词必须 URL 编码；精选池空集回退 mode=all；aihot.virxact.com 判 B 级不可作唯一来源；A 级占比 ≥30% 纪律不变。详见 `references/sources.md`「AIHOT 聚合 API」+「RSS 免 key 真实源」小节。
- **搜索策略**（v5.1四层搜索）：
  - **第一层：A级限定搜索**——优先使用 `site:A级域名` 限定搜索，确保A级来源占比≥30%
  - **第二层：产业新闻搜索**——按5环节搜索，每个环节至少2个来源（1中+1英），双语搜索
  - **第三层：技术突破搜索**（v5.0新增）——搜索近期学术会议和技术突破
    - 搜索关键词：`ISSCC 2026` / `VLSI Symposium 2026` / `DAC 2026` / `IEDM 2026` / `chip breakthrough`
    - 目标：捕获课堂上学到的技术在实际产业中的最新进展
  - **第四层：横向维度搜索**（v5.1新增）——覆盖单环节视角无法呈现的跨环节信息
    - 市场与需求：`HBM price trend 2026` / `DRAM contract price` / `foundry utilization rate` / `semiconductor market 2026`
    - 政策与监管：`semiconductor export control 2026` / `CHIPS Act update` / `China chip policy 2026` / `EU chip act`
    - 资本与投融资：`semiconductor funding 2026` / `foundry capex 2026` / `chip merger acquisition 2026` / `IPO semiconductor`
    - 目标：让日报从"5环节事件"升级为"市场/政策/资本/企业"多维产业全景
  - **第五层：催化剂搜索**（v5.3新增）——按 `references/catalysts.md` 注册表，搜索未来 7 天已公告的**确定时点**（法说会/财报日/政策生效日/监管审议日/行业会议），仅收已公开公告的日期，**严禁预测未公告事件**（如"预计X将发布"）
- 对每条搜索结果**即时判定来源级别**（只看URL域名，不看display text），C级直接丢弃
- **即时去重**：搜索时发现同一事件多来源→立即合并为一条，标注多个链接
- **即时时效标注**：搜索时根据发布日期与生成时间的差值，>3天立即标注`[回顾]`
- 若A级 < 30%→**立即补充搜索**（不加额外步骤，在当前搜索阶段补搜即可）
- **目标条数**：15-20条候选新闻（v4.0为9-10条），确保信息密度充足
- 输出：已分级、已去重、已标注时效的候选新闻列表（每条含：标题/URL/URL域名级别/日期/时效标签/摘要要点）

### Step 3: 分类+摘要+技术注解（一站式，~3分钟）
- **【强制】先执行文件读取**：读取 `references/classification.md` 获取分类规则和存疑仲裁表
- 对每条候选新闻：确定归属环节 + 压缩摘要 + 添加技术注解
- **摘要五要素**（v5.0升级）：主体+事件+数据+影响+**技术维度**
  - 技术维度示例：制程节点（3nm/5nm/28nm）、工艺技术（GAA/FinFET/CoWoS）、器件结构（HBM4 12层/Chiplet 2.5D）、材料类型（6N氟化氢/光刻胶）
  - 摘要长度：80-150字（v4.0为50-100字，v5.0放宽以容纳技术维度），3-5句
  - **句数控制**：3-4句 PASS，5句 WARN，≥6句 FAIL
- **技术注解**（v5.0新增）：对涉及专业术语的新闻，在摘要后添加`[技术注解: xxx]`标签
  - 注解内容：术语的技术原理简述（1-2句话），帮助微电子学生理解
  - 示例：`[技术注解: GAA（Gate-All-Around）是3nm以下节点的晶体管结构，相比FinFET沟道包围更完整，漏电更小]`
  - 不每条都加：仅对涉及非直观术语的新闻添加（如GAA、HBM4、CoWoS、NPO、Chiplet等）
- **信号层（v5.2新增，回答"什么值得看"）**：每条新闻在时间戳后追加 `| 信号: 重要性/影响方向/情绪` 三要素标签：
  - **重要性**（高/中/低）：影响范围大、牵动全链或龙头、改变竞争格局→高；局部/单点进展→低
  - **影响方向**（利好/利空/中性）：对产业链/公司基本面的**事实**影响方向（如扩产对供给=中性偏利空，订单落地=利好）；不做股价预测，只陈述方向
  - **情绪**（正面/负面/中性）：市场/业内对该事件的普遍解读情绪（财报扭亏=正面，管制加码=负面）
  - 示例：`| 信号: 高/利好/正面`；标注依据须能在摘要中找到对应事实，禁止无依据打分
- 软件平台/SaaS/市场分析等不纳入
- 每个环节内按重要性排序：影响范围 > 技术突破 > 市场规模 > 企业动态
- **目标条数**：15-20条（每环节3-4条），确保信息密度充足
- 输出：分类完成、摘要压缩、技术注解添加、排序确定的新闻列表

### Step 4: 组装日报（一次性做对，~2分钟）
- 按输出格式模板组装，**组装时一次性检查以下易错项**（防抖：减少门禁往返）
  - ✅ 头部元信息：生成时间、覆盖范围、新闻总数（必须与实际条数一致）
  - ✅ 今日要点：1-3条最重要新闻
  - ✅ 5个环节标题全部出现（无新闻标注"今日暂无重要动态"）
  - ✅ 每条新闻的[回顾]标签已标注（超72小时）
  - ✅ 每条摘要3-5句，含技术维度（80-150字）
  - ✅ 涉及专业术语的新闻已添加`[技术注解: xxx]`
  - ✅ 每条新闻已标注`| 信号: 重要性/影响方向/情绪`（软指标，覆盖率≥80%）
  - ✅ 产业链关联小节已编写（串联当日新闻的上下游影响）
  - ✅ 费曼解释小节已编写（大白话+类比，覆盖当日难懂术语）
  - ✅ 深度解读小节已编写（2-4 条最重要新闻：意味着什么/未来影响/格局意义）
  - ✅ 未来借鉴小节已编写（趋势信号含强度标注/格局预判/格局时间轴/可借鉴行动/风险提示）
  - ✅ 今日导师课小节已编写（今日速览/深度第一课/必懂概念/课后思考 四模块）
  - ✅ 来源分级统计与实际URL域名一致
  - ✅ 无附录越界（产业链关联和术语速查不算附录，是日报正文组成部分）
  - ✅ 尾部免责声明 + "---"分隔线
- **横向维度扩展**（v5.1新增，提升信息广度）：在5个产业链环节之后、产业链关联之前，按需新增横向事实维度小节，覆盖单环节视角无法呈现的跨环节信息：
  - `## 市场与需求`：行业供需、价格趋势、产能利用率、景气度等客观事实（如"HBM4 合约价 Q2 环比 +15%，受 AI 服务器拉动"），须附数据支撑与背景说明，严禁涨跌预测/荐股。
  - `## 政策与监管`：各国出口管制、产业补贴、安全审查等事实（如"美更新对华半导体设备管制清单"），须标注发布机构与日期。
  - `## 资本与投融资`：融资、并购、IPO、产线投资等事实（如"某厂宣布 200 亿美元先进制程扩产计划"），须标注金额、轮次、参与方。
  - 格式：用 `### 子标题` + 段落（含内联 A/B 级来源链接）承载，不强制 `**标题** — 摘要 | 来源:` 新闻条目格式，故不计入条数软指标，但来源同样须 A/B 级。
  - 目标：让日报从"单环节事件罗列"升级为"覆盖市场/政策/资本/企业的多维产业全景"。
- **产业链关联**（v5.0新增）：在自检结果前添加"## 产业链关联"小节
  - 内容：选取2-3组当日新闻中有上下游关联的事件，简述其产业链传导逻辑
  - 示例："台积电涨价(制造) → AI芯片设计公司BOM成本上升(设计) → 先进封装需求可能受影响(封测)"
  - 目标：帮助微电子学生理解产业链各环节的联动关系
- **持续追踪**（B·v5.3新增）：在产业链关联后添加"## 持续追踪"小节
  - 内容：从 `state/report_state.yaml` 读取追踪主题，逐条对比当日新闻，标注变比变化与连续期数
  - 格式：`- **[主题]**：方向（连续N期）Δ 变比 — 当日进展摘要。` 若无当日进展则写"本期无新进展"
  - 联动：今日要点若有相关新闻引用该主题，小节内标注"详见今日要点第N条"
  - 失败降级：状态文件缺失或 0 活跃主题 → 标注"暂无持续追踪主题"，不 FAIL
- **前瞻催化剂**（C·v5.3新增）：在自检结果前添加"## 前瞻催化剂"小节
  - 内容：未来 7 天已公告的确定时点（法说会/财报日/政策生效日/监管审议日/行业会议），表格化呈现
  - 格式：`| 日期 | 事件 | 环节 | 重要度 | 来源 |`；**只列已公告日期，严禁预测未公告事件**；每条须附来源链接（A/B级）
  - 失败降级：0 个已知催化剂 → 标注"近期无已知催化剂"，不 FAIL
- **费曼解释**（v5.4新增，面向零基础读者）：在"前瞻催化剂"后、自检结果前添加"## 费曼解释"小节
  - 目的：日报读者不一定懂芯片术语，`[技术注解]` 是专业版（给微电子学生），费曼解释是**通俗版**（给完全不懂的读者）
  - 内容：把当日新闻中出现的**难懂术语**用大白话+日常类比解释，每条 1-3 句，通常 5-12 条
  - 写作规则（F1.3）：
    1. **假设读者零基础**——不能用术语解释术语（解释 HBM 时不能说"DRAM"，要说"内存芯片"或顺带一句带过）
    2. **必须先给日常类比**——把抽象技术映射到生活场景（如 HBM="贴身数据快递员"、TSV="楼内电梯"、光刻="拿光在硅片上印电路"）
    3. **结构固定**：`- **术语名**：它是什么（一句大白话，含类比）。为什么重要：对芯片/行业影响（一句）。`
    4. **覆盖当日所有难懂术语**——对照各条新闻的 `[技术注解]` 收集，确保读者在正文看到的每个专业词都能在小节里查到
    5. 不预测股价、不做投资建议——只解释"是什么、为什么重要"
  - 示例：`- **HBM（高带宽内存）**：AI 芯片的"贴身数据快递员"，紧贴芯片快速搬运数据。为什么重要：AI 算得快但数据送不过来会"饿肚子"，HBM 解决喂饭速度，是 AI 服务器的核心部件。`
- **深度解读**（v5.6新增，面向"看不懂新闻意义"的读者）：在"费曼解释"后添加"## 深度解读"小节
  - 目的：费曼解释解决"这个词是啥"，深度解读解决"**这件事意味着什么**"——把当日最重要的 2-4 条新闻，翻译成读者能懂的"意义+影响+格局"
  - 选材：从今日要点 + 高信号（重要·高/利空等）新闻中选 2-4 条最重要的，非逐条解读
  - 格式：每条 `### 解读 N：标题（环节）`，下含三个固定部分（结构必须完整）：
    1. `- **这意味着什么**`：事件本质的大白话 + 一个日常类比（如涨价="给奢侈品做精装礼盒"）
    2. `- **未来影响**`：分短期（1年内）/中期（1-3年）/长期（3-5年）讲清时间线影响
    3. `- **格局意义**`：对世界产业格局/中国/普通人/产业链上下游意味着什么（挑相关维度）
  - 写作规则：每条 150-300 字；只做客观影响分析，不预测股价、不给买卖建议
- **未来借鉴**（v5.6新增，v5.8 强化，独立"借鉴性"功能）：在"深度解读"后添加"## 未来借鉴"小节
  - 目的：从当日新闻提炼**对未来的启示**——不只是"今天发生了什么"，而是"明天会怎样、你可以借鉴什么"
  - 格式：五个固定类目（`- **类目**：内容`），每类 2-4 条：
    1. `- **趋势信号**`：哪些趋势在加速/被确认（如"AI 瓶颈从算力转向存储与封装"）。**v5.8 每条末尾加强度标注 `（强度：↑强 / →中 / ↓弱）`**——用符号+强弱让读者一眼看出可信度
    2. `- **格局预判**`：1-3 年后产业/世界格局会怎么变（如"存储三强+长鑫新格局成型"）
    3. `- **格局时间轴**`（v5.8 新增）：用 `1. **1 年内**：…… 2. **1-3 年**：…… 3. **3-5 年**：……` 分阶段讲清未来演化路径（HTML 中渲染为水平时间轴）
    4. `- **可借鉴行动**`：给普通读者/创业者/投资者的可操作启示（研究地图、产业链思维、消费决策等）
    5. `- **风险提示**`：需要警惕的相反面（周期见顶、管制加码、情绪炒作等）
  - 写作规则：每条 1-3 句；克制不夸大，风险提示必须有（避免单向乐观）；强度标注只用于趋势信号
- **今日导师课**（v5.8新增，面向"我是学生看不懂日报"的读者）：在"未来借鉴"后添加"## 今日导师课"小节
  - 目的：把整份日报当**一节课**讲透——费曼解释解决"这词是啥"，深度解读解决"这新闻意味着什么"，导师课解决"**整份日报在讲什么、我该怎么想**"，全程学生视角大白话
  - 格式：四个固定模块（`### 模块名`）：
    1. `### 今日速览`：用**一个类比**把今天所有大新闻串成一条主线（如"AI 是胃口巨大的客人，饭馆正在抢着升级上菜系统"），1-2 段
    2. `### 深度第一课`：选今日最值得弄懂的 **1 件事**掰开揉碎讲透——标题带冒号（如"深度第一课：AI 的内存到底卡在哪儿？"），先给一句"先记住的话"，再分"问题出在哪/现在怎么解决/今天的新闻在吵什么/这一课的要点"讲清
    3. `### 必懂概念`：把费曼解释里最核心的 3-5 个概念升级为"导师重点划"，每条 `- **词**：一句话关系/类比`，帮读者记住概念间的联系
    4. `### 课后思考`：2-3 道引导性问题（`1. ……？`），让读者带着问题自己想一想——不直接给答案
  - 写作规则：全程零术语轰炸（出现术语必配类比）；只讲理解不预测股价；HTML 中渲染为独立"导师课堂"Tab
- 输出：日报草稿（含技术注解、横向维度、产业链关联、持续追踪、前瞻催化剂、费曼解释、深度解读、未来借鉴、今日导师课、自检结果小节）

### Step 5: Rubric自检+脚本校验（~30秒）
- **【强制】先执行文件读取**：读取 `references/rubric.md` 获取15项检查标准
- 逐项检查15项Rubric，显式输出自检结果表格
- **【强制】运行 `scripts/validate_report.py` 进行硬校验**
- 若有FAIL项 → 按映射表修正 → 重新组装 → 再次校验（目标：单次通过）
- 输出：最终日报

### Step 6: 保存+同步（~5秒）
- 保存日报到工作目录，命名：`芯片行业日报_YYYYMMDD.md`
- **【HTML 交付，F1.4】**：运行 `python scripts/build_report_html.py 芯片行业日报_YYYYMMDD.md --out delivery` 生成可视化 HTML 版（6 视图 Tab：日报视图 / 产业链全貌 / 多维透视 / 趋势图 / 周报对比 / 导师课堂，含产业链图谱、信号层标签、费曼解释卡片、深度解读、未来借鉴（强度标注+格局时间轴）、历史走势与跨期对比、导师课堂），供用户网页浏览
- **【multi_source 三件套，迭代1】**：依次运行 `python scripts/multi_source/health_check.py`、`python scripts/multi_source/value_score.py`、`python scripts/multi_source/report_viz.py`（任一步失败不阻塞交付，fail-soft），产出源健康度 `state/source_health.yaml`、量化价值分 `state/value_score.json`、多源融合报告 `delivery/multi_source_report.html`，供维护者评估数据源质量
- **【Obsidian 知识库归档，迭代3】**：运行 `python scripts/archive_to_kb.py --report 芯片行业日报_YYYYMMDD.md --kb-root "D:\我的知识库"`——归档到 `07-芯片行业日报/日报归档/YYYY/MM/`（前置 YAML frontmatter: date/segments 供 dataview）+ 按 5 环节追加要点到 `认知卡片/MOC-设计|制造|封测|EDA|材料.md`（append-only）+ 更新 `索引.md`。幂等双保险（目标存在跳过 + `state/kb_archive_index.json` sha 校验）；KB 根不存在跳过不 FAIL
- **【B】更新跨日记忆**：更新 `state/report_state.yaml`——合并当日主题（新增/延续/结束），更新方向、streak（延续+1，反转归1）、变比；状态文件 ≤15 行，缺字段用默认值
- **【D5 信号历史累积，迭代5】**：运行 `python scripts/signal_history.py`——把当日追踪主题快照追加到 `state/signal_history.json`（幂等同日覆盖；state 缺失/已存在快照时静默跳过，不阻塞）。**每天必须跑**，这是信号强度曲线与周度复盘的累积数据源
- 输出：完成确认

### Step 7: 周度复盘（认知深化 · 迭代5，周五执行 ~2分钟）
> 把「每日信息」升级为「认知资产」：每周五日报保存后执行，生成周度复盘。
> 平时（周一~周四）跳过本步；非周五但用户要求复盘时也可手动执行。

- **【数据聚合】**：运行 `python scripts/weekly_review.py`——自动聚合本周全部日报（自然周=周一~今日）+ `state/signal_history.json`（信号演进）+ `delivery/quality_dashboard.json`（质量），生成两份产物：
  - `delivery/芯片行业周度复盘_YYYYMMDD.md`（Markdown 认知资产）
  - `delivery/芯片行业周度复盘_YYYYMMDD.html`（单文件 HTML：概览卡 + 信号强度曲线 + 演进台账 + 认知素材 + 风险 + 催化剂）
- **【AI 洞察润色】**：撰写本周主线洞察（3-5 条，存到 `state/weekly_insights_YYYYMMDD.txt`，每行一条）——结合各期「深度解读/未来借鉴/信号演进台账」，回答三个问题：①哪些信号在持续发酵（streak 延续）；②哪些被证伪或反转（⚠ 标记，如 HBM up→down）；③下周该盯什么（结合催化剂）。然后带洞察重跑：`python scripts/weekly_review.py --insights state/weekly_insights_YYYYMMDD.txt`——洞察自动注入 md「本周主线」区与 html 主线区，**两产物天然同步**（不要手改 md，改洞察文件重跑即可）
- 输出：周度复盘产物路径 + 本周主线摘要（汇报给用户时附带 1-2 句认知结论）

## 失败处理

| 情况 | 修复 | 兜底 |
|---|---|---|
| 来源链接失效 | 标注"链接待验证" | 保留标题和摘要 |
| 无法确认时间 | 标注"日期待确认" | 只保留日期不保留时分 |
| 无新闻的环节 | 标注"今日暂无重要动态" | 不省略该环节 |
| 搜索无结果 | 切换为备用搜索引擎重试一次 | 标注"该环节信息获取失败" |
| 摘要过长（>150字或≥7句） | 回到Step 3重新压缩，按句数控制 | 兜底保留原文前3句 |
| 信息冲突（多源报道矛盾） | 标注各方说法，注明信息存在分歧 | 不做主观判断 |
| 涉及非公开信息 | 自动跳过，不纳入日报 | 不标注 |
| sources.md 不存在 | 回退至公开新闻源（SEMI/TechInsights/TSMC等） | 正常生成日报 |
| 分类存疑 | 按 classification.md 的存疑仲裁规则确定默认归属 | 归入"综合/其他" |
| A级来源不足30% | 补充搜索权威源（基于URL域名判定） | 标注"今日权威源不足" |
| Rubric循环超5次 | 保留最后一次结果，在自检结果中标注FAIL项 | 正常输出 |
| 未来日期新闻 | 标注"日期异常"，检查是否笔误 | 修正日期或删除该条 |
| 0条新闻（节假日） | 所有环节标注"今日暂无重要动态" | 来源质量检查自动PASS |
| 非交互模式（定时任务） | Step 1使用默认日期范围 | 不等待用户输入 |
| 负面新闻/安全事故（如工厂火灾） | 如实记录事实，标注多方说法 | 不做主观评价，不隐瞒 |
| 争议事件/多源报道矛盾 | 标注各方说法，注明"信息存在分歧" | 不做主观判断，保留各方观点 |
| 未经验证的独家爆料 | 标注"待验证"，不作为独立新闻条目 | 除非有第二独立来源佐证 |

## 边界

- 只汇总公开可访问的新闻来源，不引用付费墙内容。
- **不做投资建议或市场预测**——但允许技术解读：解释技术原理、制程节点、工艺差异是事实说明，不是投资建议。
- **不做技术分析或深度评测**——但允许技术注解：用1-2句话解释术语原理是学习辅助，不是深度评测。
- 不按股价涨幅、市值变化等金融指标排序——按重要性（影响范围>技术突破>市场规模>企业动态）排序。
- 时间戳以来源页面的发布时间为准，**72小时判定基于日期差（天数差>3则标注[回顾]）**。
- 不引用社交媒体（微博、Twitter等）未经验证的传言。
- 不翻译外文新闻标题，保留原标题并附中文摘要。非英文外文标题可附中文译名（标注"译"字）。
- **"产业链关联"小节提供事实传导逻辑**（A事件导致B事件），不是投资建议或市场预测。
- **允许"市场与需求 / 政策与监管 / 资本与投融资"等横向事实维度章节**——这些是客观事实汇总（供需、价格、政策、融资、并购），不是投资建议或市场预测。判断标准：只陈述可核查的事实与数据，不做涨跌预测、不荐股。
