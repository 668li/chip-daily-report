# Chip Daily Report

> 类型 P4：产物生成型

## 设计哲学

- **信源优先**：每条新闻必须可追溯至原始来源，拒绝二次转载未标注出处的内容。
- **产业链完整性**：宁可某环节标注"暂无动态"，也不省略环节——完整性是日报可信度的基石。
- **时效性优先**：默认覆盖最近一个工作日，超72小时的内容需标注"回顾"。
- **中立客观**：只汇总事实，不做评论、不做预测、不做投资建议、不做技术分析。
- **来源分级**：权威源优先，聚合页次之，社媒禁止——来源质量决定日报可信度。
- **执行闭环**：规则必须可执行、可验证，Rubric是门禁不是装饰——自检结果必须显式输出。

生成带来源和时间戳的芯片行业日报，覆盖设计、制造、封测、EDA、材料、设备等全产业链。

## 来源可靠性分级

| 级别 | 来源类型 | 示例 | 使用规则 |
|------|----------|------|----------|
| A级（权威） | 官方/行业组织/权威媒体 | TSMC官方、Samsung Newsroom、SEMI、TechInsights、SemiAnalysis、EDN、Semiconductor Engineering | 优先使用，**至少30%新闻来自A级** |
| B级（聚合） | 新闻聚合平台/门户 | 今日头条、新浪、网易、搜狐、雪球 | 可使用，但需追溯到原始来源并标注 |
| C级（禁止） | 社交媒体/未验证 | 微博、Twitter、抖音、知乎帖文 | **禁止使用** |

**执行**：搜索后，对每条来源判定级别。若A级不足30%，补充搜索权威源。

## 产业链环节定义（分类判定）

每个新闻必须按以下定义归入对应环节。**分类存疑时归入"综合"，不要强行塞入不相关环节。**

### 设计
- **包含**：GPU/CPU/AI芯片产品设计、芯片架构(如3D架构/Chiplet)、IP授权、芯片规格发布、性能基准测试
- **不包含**：制造工艺、封装、EDA工具本身

### 制造
- **包含**：晶圆代工(台积电/三星/中芯等)、先进制程(2nm/3nm/5nm)、成熟制程(28nm及以上)、产能扩充/缩减、代工价格、HBM/DRAM/NAND存储芯片制造、晶圆厂动态
- **不包含**：芯片设计、封装测试、制造设备

### 封测
- **包含**：封装技术(先进封装/传统封装/3D封装)、测试方案、HBM封装工艺(MR-MUF/混合键合)、封测厂动态
- **不包含**：晶圆制造、裸片设计

### EDA / 工具
- **包含**：EDA软件(Synopsys/Cadence/Siemens)、设计自动化工具、IP库、TCAD仿真、验证工具
- **不包含**：芯片产品本身、制造设备

### 材料 / 设备
- **包含**：硅片/特气(氟化氢/氢氟酸)/光刻胶/靶材/CMP材料等、光刻机/刻蚀机/沉积设备/量测设备、设备市场预测
- **不包含**：芯片产品、软件工具

### 不纳入日报的内容
- **软件平台/SaaS应用**（如AI办公平台）→ 不属于芯片产业链
- **市场指数/股价/财经分析** → 违反"不做市场分析"边界
- **AI大模型发布/应用** → 不属于芯片产业链
- **二手交易平台/消费应用** → 不属于芯片产业链

## 生成流程（程序式，必须按序执行）

### Step 1: 确认范围
- 询问/确认日期范围（默认最近一个工作日）和关注领域
- 输出：`[日期范围]` + `[关注领域]`

### Step 2: 搜索收集
- 按产业链5环节依次搜索（见"搜索策略"）
- 每个环节至少查2个来源，双语搜索
- 对每条来源判定级别（A/B/C），C级直接丢弃
- 输出：每环节的候选新闻列表（含原始标题/链接/时间/来源级别/原文摘要）

### Step 3: 来源质量检查
- 统计A级来源占比
- 若A级 < 30%，补充搜索权威源（SEMI/TechInsights/TSMC官方等）
- 输出：达标后的新闻列表

### Step 4: 分类判定
- 对每条候选新闻，按"产业链环节定义"确定归属环节
- 分类存疑时归入"综合/其他"，不要强行塞入不相关环节
- 软件平台/SaaS/市场分析等不纳入
- 输出：分类后的新闻列表

### Step 5: 摘要压缩
- 对每条新闻，将原文压缩为50-100字摘要
- **压缩操作**：保留[主体]+[事件]+[关键数据]+[影响]，删除形容词/背景/评论
- **字数控制**：以"句"为计量单位，目标3-4个完整短句（每句约20-25字），避免逐字计数偏差
- 压缩示例：
  - 原文(280字)："7月14日，SK海力士宣布面向英伟达下一代AI平台Vera Rubin的12层堆叠HBM4正式启动量产出货，产品已通过全部质量认证。CEO郭鲁正预测2027年将成为存储行业供应最紧张的一年，HBM价格预计从当前约2美元/Gb飙升至4-5美元/Gb..."
  - 压缩(85字，3句)："SK海力士启动12层HBM4量产出货英伟达Vera Rubin平台。Q1以58%份额领跑HBM市场。CEO预测2027年供需缺口扩大。"
- 输出：压缩后的摘要

### Step 6: 时效标注
- 检查每条新闻的发布时间
- 超72小时 → 标题前加`[回顾]`标签
- 无法确认时间 → 标注"日期待确认"
- 输出：带时效标签的新闻列表

### Step 7: 去重合并
- 同一事件多来源报道 → 合并为一条，标注多个链接
- 输出：去重后的新闻列表

### Step 8: 重要性排序
- 每个环节内按重要性排序：影响范围 > 技术突破 > 市场规模 > 企业动态
- 输出：排序后的新闻列表

### Step 9: 组装日报
- 按输出格式模板组装
- 必须包含：头部元信息、今日要点、5环节正文（+综合环节如有）、尾部免责声明
- 输出：日报草稿

### Step 10: Rubric门禁自检（强制循环 + 显式输出）
- 逐项检查13项Rubric
- **必须显式输出自检结果**：在日报末尾附"## 自检结果"小节，列出每项 PASS/FAIL
- **任一"必须"项不通过 → 回到对应Step修正 → 重新组装 → 再次自检**
- 循环直到全部通过，或达到3次修正上限
- 输出：最终日报（含自检结果小节）

## 搜索策略

1. **多源搜索**：每个产业链环节至少查询 2 个不同来源，交叉验证信息准确性。
2. **优先级排序**：优先引用 sources.md 中列出的优先来源；若 sources.md 不存在，回退至公开新闻源（SemiAnalysis、TechInsights、TSMC官方、EDN、Semiconductor Engineering等）。
3. **时效性过滤**：优先选择 48 小时内的新闻，超过 72 小时的新闻需标注"回顾"标签。
4. **去重处理**：同一事件被多个来源报道时，合并为一条，标注多个来源链接。
5. **双语搜索**：同时使用中文和英文关键词搜索，确保覆盖国内外新闻。

## 质量检查清单（Rubric · 门禁制 · 显式输出）

生成日报后，**必须逐项自检并在日报末尾输出结果**。标记"必须"的项不通过则修正后重新输出：

| # | 检查项 | 通过标准 | 级别 |
|---|--------|----------|------|
| 1 | 产业链完整性 | 5个环节全部出现，无新闻的环节标注"今日暂无重要动态" | 必须 |
| 2 | 来源可追溯 | 每条新闻附带可点击的来源链接 | 必须 |
| 3 | 时间戳准确 | 每条新闻标注发布时间，无法确认时标注"日期待确认" | 必须 |
| 4 | 摘要规范 | 每条摘要3-4个短句（约50-100字），包含关键数据/事件/影响 | 必须 |
| 5 | 时效性 | 超72小时新闻标注"[回顾]" | 必须 |
| 6 | 信源可靠性 | 仅引用公开可访问的正式新闻源，C级来源禁止 | 必须 |
| 7 | 中立性 | 只汇总事实，不含评论、预测、投资建议或技术分析 | 必须 |
| 8 | 去重 | 同一事件多个来源报道时合并为一条 | 必须 |
| 9 | 元信息完整 | 报告头部包含生成时间、覆盖范围、新闻总数 | 必须 |
| 10 | 今日要点 | 精选1-3条最重要新闻作为摘要 | 必须 |
| 11 | 分类正确 | 每条新闻归入正确环节，软件/市场分析类不纳入 | 必须 |
| 12 | 无附录越界 | 不出现"市场与政策动态"等越界附录 | 必须 |
| 13 | 来源质量 | A级权威源占比≥30% | 必须 |

**门禁规则**：
1. 任何"必须"项不通过 → 修正 → 重新组装 → 再次自检
2. 最多3次循环
3. **自检结果必须显式输出**（在日报末尾附"## 自检结果"表格）——不允许笼统声称"已自检通过"

## 失败处理

| 情况 | 修复 | 兜底 |
|---|---|---|
| 来源链接失效 | 标注"链接待验证" | 保留标题和摘要 |
| 无法确认时间 | 标注"日期待确认" | 只保留日期不保留时分 |
| 无新闻的环节 | 标注"今日暂无重要动态" | 不省略该环节 |
| 搜索无结果 | 切换为备用搜索引擎重试一次 | 标注"该环节信息获取失败" |
| 摘要过长（>100字） | 回到Step 5重新压缩，按句数控制 | 兜底保留原文前3句 |
| 信息冲突（多源报道矛盾） | 标注各方说法，注明信息存在分歧 | 不做主观判断 |
| 涉及非公开信息 | 自动跳过，不纳入日报 | 不标注 |
| sources.md 不存在 | 回退至公开新闻源（SEMI/TechInsights/TSMC等） | 正常生成日报 |
| 分类存疑 | 归入"综合/其他"环节 | 不强行塞入不相关环节 |
| A级来源不足30% | 补充搜索权威源 | 标注"今日权威源不足" |
| Rubric循环超3次 | 保留最后一次结果，在自检结果中标注FAIL项 | 正常输出 |

## 边界

- 只汇总公开可访问的新闻来源，不引用付费墙内容。
- 不做投资建议或市场预测。
- 不做技术分析或深度评测——日报是事实汇总，不是分析报告。
- 不按股价涨幅、市值变化等金融指标排序——按重要性（影响范围>技术突破>市场规模>企业动态）排序。
- 时间戳以来源页面的发布时间为准，不做时区换算推断。
- 不引用社交媒体（微博、Twitter等）未经验证的传言。
- 不翻译外文新闻标题，保留原标题并附中文摘要。
- **不设置"市场与政策动态"附录**——市场分析违反中立性边界，不应以附录形式绕过。市场分析类内容如需发布，应作为独立报告，不混入日报。

| 6 | 按股价涨幅或市值变化排序新闻 | 金融指标不等于新闻重要性 | 按影响范围>技术突破>市场规模>企业动态排序 |

| 8 | 把软件/SaaS/AI应用塞入材料设备环节 | 不属于芯片产业链 | 按分类判定规则归类，不属于产业链的不纳入 |
