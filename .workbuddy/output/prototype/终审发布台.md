# 产品原型归档 · 终审发布台

> 归属：《高层架构设计》§6.4。触点端责任团队：内容运营组。MVP 形态为命令行终审加本地静态复核页。
> 版本：v1.0 ／ 2026-08-07 ／ business-architect

## 1. 页面与字段清单

### P1 草稿终审页（MVP）

| 区域 | 字段 | 数据来源 | 交互 |
| --- | --- | --- | --- |
| 头部元信息条 | 生成时间、覆盖范围、新闻总数 | 日报 blockquote 三行（X16 裁决格式） | 只读，与声明值一致性由校验器核对 |
| 正文区 | 今日要点、设计、制造、封测、EDA / 工具、材料 / 设备、产业链关联 | 组装与产业链关联模块输出 | 点击条目跳转条目校对页 |
| 自检表区 | 15 行检查项、结果、说明（脚本口径，X5/X6 裁决） | 硬校验器输出 | 展开 FAIL 与 WARN 明细 |
| 来源分级统计区 | A 级来源与条数、B 级条数、A 级占比与达标标记（三行文本，X14 裁决） | 硬校验器域名判级结果 | 只读 |
| 操作条 | 回退重跑、发布、放弃 | — | 门禁未过时发布禁用 |

### P2 门禁详情页（MVP）

| 区域 | 字段 | 交互 |
| --- | --- | --- |
| 原始输出区 | 校验器逐项打印文本与退出码 | 复制、按检查项筛选 |
| 失败定位区 | FAIL 项编号、命中条目、Rubric-Step 映射目标步骤 | 一键触发指定 Step 回退重跑 |
| 修正建议区 | 按检查项给出的修正指引 | 复制到条目校对页 |

### P3 条目校对页（MVP）

| 字段 | 约束 | 交互 |
| --- | --- | --- |
| 标题 | 不得以股价或指数为主语（X11 裁决） | 编辑 |
| 摘要 | 3-5 句、80-150 字、含技术维度五要素（X3 裁决） | 编辑，实时句数计数 |
| 来源链接 | markdown 可点击格式，C 级禁止 | 编辑，实时域名判级回显 |
| 时间戳 | 至少到日期，超 72 小时需回顾标签 | 编辑，自动计算差值 |
| 环节归属 | 5 环节之一或综合其他，HBM 归制造（X9 裁决） | 下拉切换 |
| 技术注解 | 命中术语表必须有 1-2 句原理说明 | 编辑，术语命中高亮 |

### P4 发布确认页（MVP）

| 字段 | 约束 |
| --- | --- |
| 归档文件名 | `芯片行业日报_年月日.md` |
| 免责声明 | 分隔线加固定声明文本 |
| 产业链关联组数 | 不少于 2 组且每组涉及不少于 2 环节 |

### P5 争议标记页（完整版，对应 F15）

| 字段 | 说明 |
| --- | --- |
| 争议条目 | 引用条目编号与标题 |
| 争议类型 | 误分类 / 边界越界 / 术语注解错配 |
| 处置理由 | 自由文本，月度汇总回流存疑仲裁表 |

## 2. 关键交互约束

- 首屏（正文加 15 行自检表）加载 P95 不超过 2 秒。
- 核心路径不超过 4 步：打开草稿 → 复核自检表 → 逐条抽查 → 确认发布。
- 校验器退出码为 1 时发布按钮强制禁用，无命令行绕过参数。
- 任一条目被修改后必须重新触发完整校验，禁止改完直接发。
