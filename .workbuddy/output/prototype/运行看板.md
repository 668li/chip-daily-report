# 产品原型归档 · 运行看板

> 归属：《高层架构设计》§6.5。触点端责任团队：运维平台组。
> 呈现形态受 §4.2 部署形态中间确认结论影响：若最终裁定为纯本地定时形态，页面降级为命令行报表与日志视图，页面清单与指标口径保持不变。
> 版本：v1.0 ／ 2026-08-07 ／ business-architect

## 1. 指标口径定义

| 指标 | 口径 | 目标值 | 对齐目标 |
| --- | --- | --- | --- |
| 任务成功率 | 成功出报期数 ÷ 应出报期数 | MVP 不低于 95%，完整版不低于 98% | V2 |
| 门禁一次通过率 | 首次校验即全通过期数 ÷ 总期数 | 不低于 90% | V1 |
| A 级来源占比 | A 级条数 ÷（A 级条数 + B 级条数） | 不低于 30% | V1 |
| 条数区间达标率 | 条数落入 15–20 区间期数 ÷ 总期数 | 完整版不低于 90% | V5 |
| 门禁回退次数 | 单期触发 Rubric-Step 回退的次数，上限 5 | 均值不高于 1 次 | V2 |
| 告警时延 | 事件产生到触达值守的时长 | 不超过 5 分钟 | V2 |
| 三副本差异数 | 根目录与镜像逐文件 diff 差异条数 | 恒为 0 | V1 |

## 2. 页面与字段清单

### P1 运行总览页（MVP）

| 字段 | 说明 | 交互 |
| --- | --- | --- |
| 期次与日期 | 近 30 期 | 点击进入单期详情 |
| 运行状态 | 成功 / 门禁未过 / 异常 / 运行中 | 状态筛选 |
| 端到端耗时 | 含回退重跑总耗时，上限 30 分钟 | 排序 |
| 门禁回退次数 | 0 至 5 | 排序 |
| 操作 | 重跑、查看日志 | 一键重跑 |

### P2 FAIL 归因页（MVP）

| 字段 | 说明 | 交互 |
| --- | --- | --- |
| 检查项编号与名称 | 脚本口径 15 项（X5 裁决） | 按计数排序 |
| FAIL 计数 | 统计窗口内累计次数 | 下钻到具体期次 |
| 典型样本 | 命中条目摘录 | 跳转条目校对页 |

### P3 规则一致性页（MVP）

| 字段 | 说明 | 交互 |
| --- | --- | --- |
| 三副本 diff 结果 | 根目录与 TRAE 镜像逐文件比对 | 手动触发校验、查看差异明细 |
| 域名双向差集 | 注册表与脚本常量、注册表与源库两组差集 | 跳转修复指引 |
| 最近同步时间 | 上次一致性通过的时间戳 | 只读 |

### P4 告警配置页（MVP）

| 字段 | 说明 |
| --- | --- |
| 失败告警阈值 | 连续失败次数触发 |
| 超时告警阈值 | 单期耗时上限，默认 30 分钟 |
| A 级占比告警阈值 | 默认 30% |
| 通知渠道与值班人 | 渠道地址与轮值名单，支持测试通知 |

### P5 质量趋势页（完整版）

| 字段 | 说明 |
| --- | --- |
| 趋势曲线 | 一次通过率、A 级占比、条数分布 |
| 下钻维度 | 时间、产业链环节、检查项 |
| 导出 | 周报与月报导出 |

### P6 源库健康页（完整版，对应 F13）

| 字段 | 说明 |
| --- | --- |
| 域名可用性 | 探测成功率 |
| 命中率 | 近 30 期被引用次数 |
| 处置建议 | 失效标注与替换候选 |

## 3. 关键交互约束

- 看板只读运行元数据，不呈现未发布日报正文，避免形成第二个发布出口。
- 指标保留窗口 90 天，满足每周复盘与每月合规抽查回溯需求。
- 重跑动作必须重新经过门禁网关，不得跳过校验直接发布。
