## 二、抄什么清单（按对唯一读者勇谚的价值排序）

1. **话题级去重/版面防复读（抄 Horizon 的 topic_dedup + 分类上限）**——第 1 期评审实证痛点「同一 HBM 故事全文讲了 6 遍以上」。落点：gate 加同题候选去重（跨候选标题指纹去重，只留最高置信），写作纪律加「同一事件只在一个环节展开，其余引用」。→ 已列 P2-F 本轮落地
2. **「No citation → no output」写作前置纪律（抄 citation-check-skill 的两遍架构）**——先列本期事实声明清单→逐条配文章级来源→配不出源的声明禁入正文。它证明「生成阶段强制」比「事后补验」便宜。落点：SKILL.md Step 4 纪律 +（v2）validate_understanding 升级为声明级校验。→ 纪律本轮落 SKILL.md，声明级校验划 v2
3. **学习者状态文件（抄「授业」progress.json 的最小可行建模）**——给勇谚建「已修课程概念清单」结构化 JSON（电路/模电/数电/半导体物理的概念粒度），作为知识锚语义一致性校验（v2 已划界项）与「今日一课该讲什么」的地基。→ v2 地基，本轮只定 schema 草案
4. **首发时间 vs 收录时间分开标注（抄 TrendRadar 的首发时间+🆕 轨迹）**——时效账本的展示层增强：让「新闻是旧的但我知道它是旧的」变成可见。→ 台账记账，v2
5. **到期对账自动化（抄 manifold/metaculus 的异步结算任务）**——forecast_log 到期条目自动提醒四态判定，正是加时池 ①（复利引擎）。→ 加时池已有，本报告确认优先级
6. **双库收录才保留（抄 opendraft 的 ≥2 独立源收录）**——「单源孤证降级」的学术版印证；我们 G3+[G-3] 方向正确，价值分可参考其「≥2 收录」口径。→ 已等效，无需动

## 三、避什么清单

1. **多渠道推送矩阵**（Horizon 的飞书/钉钉/TG/微信 webhook 矩阵）：单一读者=零边际价值，纯维护负担。
2. **通用热榜聚合赛道**（TrendRadar 62.5k★ 的主战场）：红海+与「为一个人教学」定位相反；只抄它的时效展示，不进它的赛道。
3. **NLI/GPU 蕴含模型做引文核实**：单机无 GPU 的 Python 门禁玩不起；启发式+检索对齐（citation-check-skill 路线）已被证明够用。
4. **预测市场式众包结算**（manifold 的 play-money 机制）：单人日报不需要众包共识，互斥剧本+四态判定更轻。
5. **热榜公共实例依赖**（newsnow 403 教训，已记 v7 复盘）：热榜类一律自部署，公共实例只做兜底。

## 四、护城河地图（五论点逐条判决）

| 论点 | 判决 | 证据 |
|------|------|------|
| 1. 每日心跳+读者唯一教学层 | **教学层=独占**；心跳=持平（本轮恢复后成立） | C 组搜索页全部 23 个结果最高 5★，「日报作为教学载体」零命中；定时生成（GitHub Actions）是 Horizon/TrendRadar 标配，无差异 |
| 2. 推演可问责 | **独占**（在「每日内容产品」域内） | B 组：独立预测追踪工具生态最高 2★（brierly）；manifold/metaculus 是平台不是内容产品；「推演块嵌进日报+到期四态对账」无任何先例命中 |
| 3. 诚实性工程 | **领先** | 最接近物 citation-check-skill（248★）面向通用 LLM 输出，不做新闻时效账本/首页伪追溯/单源孤证；[G-1]~[G-4] 组合在新闻日报域内无同类命中 |
| 4. 批评代谢引擎 | **独占** | 14 个调研项目 0 个有「对抗评审→缺陷样本→门禁红灯」机制；opendraft 的静态引文规则不属于此类 |
| 5. 自主发现层 | **持平** | TrendRadar 62.5k★/RSSHub/Miniflux 均为成熟先例；我们的三引擎+密度门禁是合格工程组合但非独创，规模与社区差几个量级 |

**猜想裁决**：「2+3+4 组合在开源世界无同类」——**成立**（基于本轮可检索性证据）。护城河的真实形状：不在单点技术（发现层持平、心跳持平），而在「推演问责×诚实性×批评代谢」三件套与唯一读者的教学层绑定。前者构成系统差异，后者构成存在理由。

**防注水注记**：本调研为一次轻量快照（11 次 WebFetch 直读），「无同类」指 GitHub 可检索范围，不排除未开源/私有实现；star 数随时间变化；对照组沿用既往实测结论未经二次核验。每条判决的可信度依赖搜索词覆盖面，已尽量用英文关键词宽查询。
