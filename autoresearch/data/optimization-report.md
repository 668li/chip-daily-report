# B/C 设计优化报告（autoresearch 2026-08-09）

## B 跨日记忆 — Winner（89.4）

**设计**：轻量 YAML 状态文件（≤15 行、带默认值、失败降级）+ 变比量化（streak/方向/Δ）+ 持续追踪小节联动今日要点。

**落地要点**：
- 状态文件：`state/report_state.yaml`（机器可读，记录主题、方向、连续期数、Δ、上次日期）
- 日报输出 `## 持续追踪` 小节（放在产业链关联后）：`主题 — 方向(连续N期) Δ +x%`，联动今日要点（若某主题当天有新闻则引用）
- 失败降级：状态文件缺失 → 跳过持续追踪小节，不 FAIL；0 活跃主题 → 标注"暂无持续追踪主题"
- 检查21（软）：检测到 `## 持续追踪` 小节时验证其结构（WARN 不破坏退出码）

**V1 增强（未落地，可后续）**：变比量化更激进（自动从历史日报提取 Δ）。

## C 前瞻催化剂日历 — Winner（89.4）

**设计**：催化剂表格式小节（日期/事件/环节/重要度/来源）+ 只列确定时点（严禁预测新闻）+ 每条附来源可核查 + 0 条时标注"近期无已知催化剂"不 FAIL。

**落地要点**：
- 日报输出 `## 前瞻催化剂` 小节（放在自检结果前）：表格 `日期 | 事件 | 环节 | 重要度 | 来源`
- 只列确定时点：法说会/财报日（Tier-0）、政策生效日/监管审议（Tier-2）、行业会议（ISSCC/DAC/VLSI/IEDM）
- 严禁预测：不写"预计X将发布"，只写已公告的时点
- 0 条时：标注"近期无已知催化剂"，不 FAIL
- 检查22（软）：检测到 `## 前瞻催化剂` 小节时验证表格结构（WARN 不破坏退出码）

## 为什么这样设计（评委共识）

| 维度 | 共识 |
|------|------|
| 契合度 | 单一权威源治理风格：状态文件/催化剂清单都进 `state/` 或 `references/`，脚本只读 |
| 价值 | 直接治"效果甚微"：日报从"今天发生了什么"升级为"比昨天变了什么 + 明天会发生什么" |
| 可维护性 | 轻量优先：YAML ≤15 行、表格化小节、0 条降级，LLM 生成成本可忽略 |
| 鲁棒性 | 全部软检查 WARN 不 FAIL，旧日报零兼容成本，失败即跳过 |
| 落地意愿 | 不碰 20 项门禁、不新增脚本依赖、镜像同步只有 2 个文件 |
